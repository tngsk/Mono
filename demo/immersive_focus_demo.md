# 没頭型ドキュメント・システム

特別な区切り記号を書くことなく、普通に見出し（`#` や `##`）を書くだけで、現在読んでいる章・節が鮮明に浮かび上がり、上下が穏やかに減光されます。

## 1. 概念と操作

- **デフォルト**: 現在見ている章・節が100%で鮮明表示、上下は薄く表示（`opacity: 0.22`）
- **`J` / `K` キー** または **`↓` / `↑` キー**: 章・節ごとのスムーズ移動
- **`D` キー**: 没頭モードとフラット表示（全体100%）のトグル切り替え
- **`Z` キー**: 下のコードブロックなど特定パーツのピンポイント拡大
