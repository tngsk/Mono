# レイアウトコンポーネント（mono-layout）仕様検証

`@[hbox]` および `@[vbox]` を用いたフレックスボックス配置の検証ドキュメント。

---

## 2列均等水平配置（hbox）

@[hbox]{.gap-group}
:::
**左カラム（50%）**
- 構文: `@[hbox]{.gap-group}`
- 各カラムは `:::` で区切る。
- 横幅は均等（flex: 1）に自動分配される。
:::
:::
**右カラム（50%）**
- レスポンシブ対応: 画面幅768px未満で垂直スタックへ自動フォールバック。
:::
@[/hbox]

---

## 垂直スタック（vbox）とネスト

@[hbox]{.gap-flow}
:::
@[vbox]{.gap-item}
:::
**ボックス1**
垂直方向に密接配置（`.gap-item`）。
:::
:::
**ボックス2**
親の `@[hbox]` の左側カラム内に格納。
:::
@[/vbox]
:::
:::
@[vbox]{.gap-item}
:::
**ボックス3**
親の `@[hbox]` の右側カラム内に格納。
:::
:::
**ボックス4**
異なるギャップ幅を多重に適用可能。
:::
@[/vbox]
:::
@[/hbox]
