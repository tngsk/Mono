# セクションおよび拡大コンポーネント仕様検証

`@[section]` によるフルブリード背景分割と `@[zoom]` によるモーダル表示の検証ドキュメント。

---

## フルブリードセクション（mono-section）

@[section](padding: "group")
:::
### セクション内コンテンツ
- 構文: `@[section](padding: "flow" | "group" | "item")`
- 効果: グローバルグリッド（中央寄せ）の制約を解除し、画面全幅（100vw）に背景色を拡張。
- 内部パディング: `--space-group`（約64px）を適用。
:::
@[/section]

---

## モーダル拡大コンポーネント（mono-zoom）

クリックまたは `Z` キーで対象要素を全画面モーダルへ複製・拡大表示。解除は `Esc` キーまたはオーバーレイクリック。

@[zoom]
:::
| 項目 | 型 | 説明 |
|---|---|---|
| id | string | 要素の一意識別子 |
| value | number | 計測データ数値 |
| status | boolean | 稼働フラグ |
:::
@[/zoom]
